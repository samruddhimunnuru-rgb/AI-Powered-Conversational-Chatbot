# 🤖 AI-Powered Conversational Chatbot

An AI-powered conversational chatbot built using **Python**, **Gradio**, **Hugging Face Transformers**, and **Retrieval-Augmented Generation (RAG)**. The application enables users to upload PDF documents, ask natural language questions, and receive context-aware responses generated by a lightweight Large Language Model (LLM).

---

## 🚀 Features

- 💬 AI-powered conversational chatbot
- 📄 Upload PDF documents
- ❓ Ask questions about uploaded documents
- 🔍 Semantic search using FAISS
- 🧠 Retrieval-Augmented Generation (RAG)
- 🤖 Context-aware responses using a Lightweight LLM
- 🎨 Interactive Gradio Web Interface
- ⚡ Fast and lightweight implementation

## ⚙️ Installation



```bash

```

## 🖥️ How It Works

1. Upload a PDF document.
2. The document text is extracted using PyMuPDF.
3. The text is split into smaller chunks.
4. Sentence Transformers generate vector embeddings.
5. FAISS stores the embeddings for semantic search.
6. The chatbot retrieves the most relevant document sections.
7. A lightweight LLM generates accurate, context-aware responses.
